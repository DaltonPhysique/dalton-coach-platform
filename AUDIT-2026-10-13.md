Read-only audit of `~/workspace/coach-app` (React + Vite + Supabase). Both sides: client app + coach dashboard.

## ✅ Fixed Oct 13, 2026 (all 5 priority fixes shipped, `npm run build` passes)

1. **A3 — Checklist Reset now hits the DB** (`HomeScreen.jsx`): Reset deletes today's `checklist_completions` rows via Supabase, then clears local state. Shows "Checklist reset ✓" / honest error; on failure it reloads server truth so the UI never lies.
2. **B1 — Traffic light counts the default checklist** (new `src/lib/defaultChecklist.js` shared by client + coach): when a client has no custom `checklist_items` but has completions, the coach dashboard counts against the 9-item default list. Brand-new clients with zero activity still read "No data yet."
3. **A2 — + New Client no longer hijacks the session** (`CoachDashboard.jsx createClient`): captures the coach session before `signUp`, restores it with `setSession` after. If restore fails, signs out with "Please sign back in" — never silent.
4. **B2/B3 — Recovery + Logbook wired to the DB**: new migrations `supabase/client-recovery-logs-migration.sql` and `supabase/client-pr-logs-migration.sql` (**Dalton must run both in Supabase SQL Editor**). Screens load/save real data with loading + error states; honest "not connected yet" notice if tables are missing — no more fake "Saved ✓". Demo badges removed from both screens.
5. **A1 — Profile-null redirect loop eliminated** (`App.jsx` + `AuthContext.jsx`): new `profileError` state; `RequireAuth` shows a real error screen ("We couldn't load your profile" + Try again / Sign out) instead of bouncing /app → /app forever.
